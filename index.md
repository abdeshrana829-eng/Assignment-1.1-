### Part 1: Submission Paragraph

When you type a URL into a web browser (the client), the browser uses DNS to find the server's IP address and sends an **HTTP** or secure **HTTPS** request over the internet. The server receives this request, fetches the necessary data—often communicating with a database for a dynamic site or reading pre-built files for a static site—and sends back a response containing HTML, CSS, and JavaScript. Finally, the browser parses this code and renders the fully loaded website onto your screen in a fraction of a second.

### Part 2: Detailed Breakdown (For Your Understanding)

To help you understand each part of your assignment rubric:

* **1. Client, Server, Browser, and Database:**
* **Client / Browser:** The device or software (like Chrome on your laptop) that initiates the request and displays the website.
* **Server:** A powerful remote computer that stores website files and listens for requests from clients.
* **Database:** A structured system where a website stores dynamic data like user profiles, posts, or product catalogs.


* **2. Meanings of HTTP and HTTPS:**
* **HTTP (HyperText Transfer Protocol):** The foundational protocol used for transmitting web pages over the internet.
* **HTTPS (HyperText Transfer Protocol Secure):** The secure version of HTTP that encrypts data transferred between your browser and the server using SSL/TLS, protecting sensitive information like passwords.


* **3. The Request-Response Cycle:**
* **Request:** The browser asks the server for specific resources (e.g., "Give me the homepage").
* **Response:** The server processes the request and sends back the files (status codes like `200 OK` mean success).


* **4. Static vs. Dynamic Websites:**
* **Static Website:** Consists of fixed files (HTML/CSS) that look the same for every visitor (e.g., a simple portfolio).
* **Dynamic Website:** Generates content in real-time using databases and server-side scripts, allowing personalized experiences and user interaction (e.g., YouTube, Instagram).

### Part 3: How to Get Your Network Tab Screenshot

1. Open **Google Chrome** and go to any website (e.g., `google.com` or `github.com`).
2. Open **DevTools** by pressing `F12` on Windows (or `Cmd + Option + I` on Mac), or right-click anywhere on the page and select **Inspect**.
3. Click on the **Network** tab in the top panel.
4. Refresh the page (`F5` or `Ctrl + R`) to capture the live network traffic requests.
5. Take a screenshot of this tab showing the list of loaded requests (HTML, CSS, JS, images) and include it with your text submission!
